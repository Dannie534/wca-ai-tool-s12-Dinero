# DINERO - Smart Chama Assistant 💰

Dinero is a Kenyan chama treasurer assistant that helps track members, payments, balances and meeting summaries.

## What it does
- Chat with Dinero AI about payments
- Add members and record payments
- Track balance vs 1000 KES monthly target
- Show total collected
- Save sessions and open past sessions
